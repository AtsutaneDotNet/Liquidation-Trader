Technical Strategies

Note: At least one strategy must be enabled. If both are enabled, both must signal in the same direction.

VWAP Strategy

When enabled, the bot calculates a Rolling VWAP over the specified timeframe and period. A LONG signal is generated when the price drops below the Lower Offset, and a SHORT signal when it rises above the Upper Offset.

RSI Strategy

When enabled, the bot uses the RSI indicator to identify overbought or oversold conditions. A LONG signal is generated when RSI drops below the Oversold threshold, and a SHORT signal when RSI rises above the Overbought threshold.

ADX Strategy

When enabled, the bot uses the ADX indicator to determine the strength and direction of the trend. A trade is only considered if the ADX value is above the threshold. A LONG signal is generated when -DI > +DI, and a SHORT signal is generated when +DI > -DI.

Fear & Greed Strategy (🌟 Premium)

When enabled, the bot checks the Crypto Fear & Greed Index from RapidAPI. Fear gives a LONG signal, while Greed gives a SHORT signal. Extreme Fear and Extreme Greed yield no signal (blocking trades if confluence is required), and Neutral ignores this strategy completely, allowing other enabled strategies to decide. Requires RapidAPI Key.

Trading Core

Dynamic Thresholds (🌟 Premium)

When enabled, the bot periodically fetches dynamic, statistically-driven mean liquidation threshold values for each base asset via RapidAPI. This dynamic threshold overrides the static Min Liquidation Value Threshold for each coin, ensuring trade evaluations are triggered only by liquidations that are statistically significant relative to each coin's typical volume. Requires RapidAPI Key.

When enabled, if the dynamic liquidation threshold for a coin falls below the static Min Liquidation Value Threshold, the bot will use the static threshold instead. This ensures dynamic thresholds never drop below your absolute minimum requirement.

Risk Management

Trailing Profit

When enabled, the bot tracks your open positions and updates a trailing stop loss to lock in profits. Trailing starts when PnL reaches the Trailing Activation (%), and follows the price at a distance of Trailing Profit Distance (%).

DCA Martingale (EXPERIMENTAL)

When enabled, the bot scales the next order size based on the absolute price move percentage (PnL% / Leverage) of any existing position for the same symbol. Multiplier = ceil(abs(PnL% / Leverage)). This allows for automated Martingale-style scaling as positions go into loss or profit.

Runaway Helper (Experimental)

When enabled, if an active position becomes stale (no websocket updates) and its unrealized PnL % drops below this threshold (e.g., -10%), the bot will evaluate trade immediately for this coin using the current mark price, treating it as a large liquidation event to attempt a rescue or averaging entry. This helps if there is no liquidation stream for that coin in the longer run.
